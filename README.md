\# WeSplit



A small bill-splitting application built with SwiftUI while working through 100 Days of SwiftUI by Paul Hudson.



The project was created as a practical learning exercise to develop my understanding of Swift, SwiftUI, application state, user input and basic calculations.



\## What it does



\- Enter a bill amount

\- Select the number of people sharing the bill

\- Choose a tip percentage

\- Calculate the amount each person should pay

\- Display the result using the device's currency settings



\## Technologies



\- Swift

\- SwiftUI

\- Xcode



\## What I learned



This project provided practical experience with:



\- SwiftUI views and layouts

\- `@State` and managing user input

\- Forms, pickers and navigation

\- Working with calculated values

\- Basic Swift syntax and application structure

\- Building and testing an iOS application in Xcode
